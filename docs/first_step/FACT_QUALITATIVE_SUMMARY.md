# Факт: качественные выводы по сопоставлению текстов вакансий и резюме

Основание: сопоставление текстов из отчёта **`data/results/RANKING_COMPARISON_BY_VACANCY.md`** (топ-3 по каждому методу на одних и тех же вакансиях) и визуальный разбор нескольких вакансий (backend Node.js, C# backend, frontend React).

Это **не** метрики NDCG и **не** статистика по всему корпусу — только содержательные наблюдения для формулировок в главе.

---

## Backend: вакансия под Node.js / Nest / Kafka / gRPC

- У **E5** и **MPNet** в верхушке списка чаще оказывались резюме с явной ролью **Senior / Backend Node.js** и перечислением совпадающего стека.
- У **BM25** в топе нередко оказывались **frontend** или **Go backend** за счёт пересечения ключевых слов (Node, API, Kafka) без совпадения целевой роли.
- У **MiniLM** на отдельных вакансиях в топ попадали **нерелевантные роли** (например QA), при том что подходящие Node.js-профили в выборке были.
- У **ru_sbert** на тех же примерах в топ-3 попадали **менеджеры / продукт / аналитика**, а не целевые backend-разработчики.

## Backend: вакансия под C# / .NET

- **E5** давал в топе несколько резюме с явным **C# / .NET Backend**.
- **BM25 / TF-IDF** на проверенном примере не поднимали C#-разработчиков в топ-3 (преобладал Python и смежные формулировки).
- На том же кейсе **MiniLM, MPNet, ru_sbert** в топ-3 не выводили целевых C# backend (часто — менеджмент, стратегия, QA).

## Frontend: React, Next.js, TypeScript

- На проверенной вакансии **все методы** давали в топе **frontend-разработчиков** с близким стеком; различия между методами были менее выражены, чем на узкоспециализированных backend-вакансиях.

## Как использовать в тексте диссертации

Можно сослаться на таблицы в **`data/results/RANKING_COMPARISON_BY_VACANCY.md`** как на иллюстративный материал и кратко резюмировать: для **узких IT-ролей** различие между **лексическими и семантическими** методами заметнее; **E5** в ряде кейсов лучше согласовывал топ с формулировкой вакансии по должности и стеку.

Влияние **cross-encoder** на порядок внутри пула после порога — см. **`data/results/RERANK_COMPARISON_BY_VACANCY.md`** и **`data/results/rerank_top1_shift_stats.json`**.
