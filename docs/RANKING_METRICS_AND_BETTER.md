# Метрики ранжирования и что значит «ранжирует лучше»

## Как понимать «метод A ранжирует лучше метода B»

Мы сравниваем методы (BM25, TF-IDF, E5, …) **на одной и той же разметке релевантности**: для каждой вакансии отмечено, какие кандидаты считаются релевантными (например, топ-k по какому-то эталону).

- **«A ранжирует лучше B»** = при оценке по **NDCG**, **MAP** или **MRR** у метода A значения **выше**, чем у B.

То есть метод A чаще ставит релевантных кандидатов **выше в списке**, чем метод B. Метрики это и измеряют.

---

## NDCG (Normalized Discounted Cumulative Gain)

- **Идея:** релевантные документы в начале списка дают больший «выигрыш», с дисконтом по позиции.
- **NDCG@k:** учитываются только первые k позиций. Нормализация по идеальному порядку → значение в [0, 1].
- **Выше NDCG** = больше релевантных кандидатов расположены выше, причём с учётом того, что попадание на 1-е место ценнее, чем на 10-е.

**Вывод:** «BM25 ранжирует лучше по NDCG@10» = в среднем по вакансиям BM25 ставит релевантных кандидатов выше в топ-10, чем другой метод.

---

## MAP (Mean Average Precision)

- **Идея:** для каждой вакансии считается Average Precision (доля релевантных среди топ-k при проходе сверху вниз), затем берётся среднее по вакансиям.
- **Выше MAP** = в среднем релевантные кандидаты появляются раньше в списке.

**Вывод:** «BM25 ранжирует лучше по MAP» = в среднем по вакансиям порядок, выданный BM25, даёт более высокую точность на префиксах списка (релевантные выше).

---

## MRR (Mean Reciprocal Rank)

- **Идея:** для каждой вакансии — позиция первого релевантного кандидата; MRR = среднее по вакансиям от 1/rank.
- **Выше MRR** = первый релевантный кандидат в среднем стоит выше.

**Вывод:** «BM25 ранжирует лучше по MRR» = первый подходящий кандидат в списке BM25 в среднем появляется раньше, чем у другого метода.

---

## Практически

1. Строим разметку (например, топ-5 по BM25 = релевантные).
2. Считаем NDCG@5, NDCG@10, MAP, MRR для BM25, TF-IDF, E5 и т.д. по этой разметке.
3. Метод с **большими** значениями метрик по этой разметке **ранжирует лучше** в смысле: релевантные кандидаты оказываются выше в списке.

Важно: разметка одна и та же; сравниваем только порядок, который выдаёт каждый метод.
