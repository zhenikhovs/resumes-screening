# Подготовка к обучению (LTR)

Здесь планируется:

- Формирование датасета для Learning-to-Rank (пары/тройки вакансия–резюме с меткой релевантности).
- Скрипты разметки или загрузки уже размеченных данных.
- Обучение ранкера (pointwise / pairwise / listwise) и сохранение модели.
- Оценка по NDCG, MAP, MRR (см. `services/evaluation/`).

Пока папка — заглушка. Используйте `config.paths` и формат результатов из `services/ranking/` для единообразия путей и скоров.
